# SkyLite

> ⚠️ **Ранняя альфа.** Мод находится на ранней стадии разработки и может работать нестабильно: возможны баги и заметные изменения между версиями.

Крошечный клиентский Fabric-мод для Minecraft Java: компактный и быстрый HUD и алерты для Hypixel SkyBlock. Всё рисуется из данных, которые сервер и так присылает клиенту, — без собственных пакетов, без миксинов, без текстур и моделей.

## Возможности

- **Полоски HP / маны / опыта вместо ванильного HUD.** Каждая полоска может занять место заменяемого элемента (сердечки, голод, XP-бар): значение внутри полоски (полное / компактное / проценты), символы ❤ ✎, рамка, пульс при низком значении, настраиваемые ширина и толщина.
- **Редактор в игре (F8).** Перетаскивай полоски и плашку скорости куда угодно; колесо — ширина полоски под курсором (Ctrl+колесо — толщина), ПКМ — выбор цвета. Мягкие прилипания к ванильному месту и центру экрана; раскладка переживает смену GUI-масштаба и размера окна.
- **Плашка скорости.** Speed-стат SkyBlock голым процентом — двигается в редакторе, включается/выключается в настройках.
- **Инфо-строки.** Defense, область/остров, таймеры Cookie Buff и God Potion, Purse, Bits — парсятся из сайдбара и action bar, включаются по одной.
- **FPS и настоящий пинг.** В любом углу. Пинг измеряется тем же крошечным status-запросом, что и список серверов, в фоновом потоке — потому что на игровых серверах Hypixel подделывает пинг в табе (там всегда «1»).
- **Алерты (F7).** Звук и вспышка, когда сообщение в чате содержит любое из твоих слов (`RARE DROP!`, …); слова задаются через запятую.
- **Собственный экран настроек.** Плоский тёмный интерфейс с боковой панелью категорий (Bars, Info lines, Alerts, Vanilla HUD) и модальной палитрой цветов — только ванильные виджеты, Cloth Config не нужен; Mod Menu необязателен и добавляет лишь кнопку входа.
- **Локализация.** Русский и английский интерфейс.

## Клавиши и команды

| Клавиша | Действие |
| --- | --- |
| `F6` | включить/выключить весь HUD SkyLite |
| `F7` | включить/выключить алерты |
| `F8` | редактор полосок и плашки скорости (переназначается в «Управлении») |

`/skylite` — экран настроек · `/skylite edit` — редактор · `/skylite hud`, `/skylite alerts` — переключатели.

## Поддерживаемые версии

Выберите файл под свою версию игры:

- **26.3** — `skylite-0.1.5+26.3.jar`

## Требования

- **Minecraft 26.3** — единственная поддерживаемая версия (Fabric); других линий игры пока нет.
- **Fabric Loader 0.19.5 или новее.**
- **Fabric API** — обязателен; без него мод не загрузится.
- **Java 25 или новее** — лаунчеры обычно ставят её сами для этой версии игры.
- **Только клиент** — мод устанавливается в клиент, на сервере ничего не нужно.

Необязательно: **Mod Menu** — добавляет кнопку SkyLite в список модов (без него всё работает).

## Как пользоваться

1. Положите Fabric API и файл SkyLite в папку `mods`.
2. Запустите игру. На SkyBlock полоски заменят ванильный HUD; `F6`/`F7` переключают HUD и алерты.
3. `F8` (или `/skylite edit`) — расставить и раскрасить всё; `/skylite` — полный экран настроек.

## Сборка из исходников

Нужны JDK 25 и Gradle:

```bash
bash tools/build_all.sh   # → dist/skylite-0.1.5+26.3.jar
```

## Раскрытия

**Данные и приватность.** Пока включён виджет FPS/пинга, SkyLite отправляет тому же серверу, к которому вы подключены, крошечный status-запрос серверного списка (примерно раз в 3 секунды), чтобы измерить реальное время отклика. Больше ничего никуда не отправляется; автор не собирает и не хранит данные.

**ИИ-контент.** Проект создан автором совместно с генеративными ИИ-инструментами (ChatGPT и OpenCode). Все решения по продукту, дизайну и тестирование в игре выполнены автором; значительная часть кода написана с помощью ИИ.
