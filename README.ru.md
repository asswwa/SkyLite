# SkyLite

> ⚠️ **Ранняя альфа.** Мод находится на ранней стадии разработки и может работать нестабильно: возможны баги и заметные изменения между версиями.

Клиентский Fabric-мод для Minecraft Java: компактный и быстрый HUD для Hypixel SkyBlock. Полоски HP, маны и опыта (шесть стилей) вместо ванильных элементов, инфо-строки из сайдбара (Defense, область, таймеры Cookie Buff и God Potion, Purse, Bits, эффекты, координаты, статистика сессии), плашка скорости, FPS и настоящий пинг в углу, алерты на редкие дропы и журнал дропов, инструменты для чата и вкладка «Оптимизация» с пресетами графики в один клик. Всё рисуется из данных, которые сервер и так присылает клиенту: без миксинов, без текстур, без собственных пакетов.

Поддерживаемая версия игры: **26.3** (Fabric).

## Возможности

- **Полоски HP / маны / опыта вместо ванильного HUD.** Шесть стилей (классика, скруглённые, капсула, глянец, минимал, обрамлённая); каждая полоска может занять место заменяемого элемента (сердечки, голод, XP-бар): значение внутри полоски (полное / компактное / проценты), символы ❤ ✎, рамка, пульс при низком значении, настраиваемые ширина и толщина.
- **Редактор в игре (F8).** Перетаскивай полоски, плашку скорости и каждую инфо-строку; колесо — ширина полоски под курсором (Ctrl+колесо — толщина), ПКМ — выбор цвета. Стрелки сдвигают выбранный элемент на 1 px (Shift — 10), двойной клик сбрасывает; мягкие прилипания к ванильному месту и центру экрана. Раскладка переживает смену GUI-масштаба и размера окна.
- **Плашка скорости.** Speed-стат SkyBlock голым процентом — двигается в редакторе, включается/выключается в настройках.
- **Инфо-строки.** Defense, область/остров, таймеры Cookie Buff и God Potion, Purse, Bits, активные эффекты, координаты, реальное время, время сессии, AFK-таймер и дропы за сессию — парсятся из сайдбара и action bar; каждая строка — отдельный перетаскиваемый блок с необязательной подписью. Лимит строк (0–16) обрезает стопку по высоте экрана.
- **FPS и настоящий пинг.** В любом углу, с опциональным бейджем LAG, когда пинг превышает настраиваемый порог. Пинг измеряется тем же крошечным status-запросом, что и список серверов, в фоновом потоке — потому что на игровых серверах Hypixel подделывает пинг в табе (там всегда «1»).
- **Алерты (F7).** Выбор звука (колокольчик, плинк, XP-орб, клик), громкость и длительность; алерты встают в очередь, а не накладываются, с кулдауном, дедупом и тёмной подложкой под тостами и вспышкой. Встроенные алерты на скорое истечение Cookie Buff/God Pot и эффектов, низкий уровень HP/маны, полный инвентарь, упоминание ника и кик в Limbo/лобби; пресеты для пати, трейда, визитов, рестарта сервера и `RARE CATCH`.
- **Журнал редких дропов.** Каждый редкий дроп пишется со временем и локацией; открывается через `/skylite drops` или из вкладки Alerts. Опциональный скриншот при редком дропе.
- **Инструменты для чата.** Ник подсвечивается, опциональный алерт срабатывает на упоминание. Таймстемпы, фильтр спама, свои правила `фраза => sound+toast+hl+hide` с игнор-листом и готовые пресеты для рекламы визитов, гивэвеев и сообщений лобби.
- **Вкладка «Оптимизация».** Пресеты ванильной графики в один клик (Сбалансированный / Производительность / Максимум) с откатом к состоянию до оптимизации, советник по остальным настройкам, рекомендуемые моды производительности, профили по локациям (с проверкой правил на лету) и 10-секундный замер FPS, который запоминает прошлый результат и показывает разницу.
- **Собственный экран настроек.** Плоский тёмный интерфейс с боковой панелью категорий (Bars, Info lines, Alerts, Chat, Vanilla HUD, Optimization) и модальной палитрой цветов — только ванильные виджеты, Cloth Config не нужен; Mod Menu необязателен и добавляет лишь кнопку входа. У каждой настройки есть подсказка при наведении; поиск подсвечивает совпадения и показывает счётчик.
- **Локализация.** Русский и английский интерфейс.

## Клавиши и команды

| Клавиша | Действие |
| --- | --- |
| `F6` | включить/выключить весь HUD SkyLite |
| `F7` | включить/выключить алерты |
| `F8` | редактор HUD — полоски, плашка скорости и инфо-строки (переназначается в «Управлении») |

`/skylite` — экран настроек · `/skylite edit` — редактор · `/skylite hud`, `/skylite alerts` — переключатели · `/skylite drops` — журнал редких дропов · `/skylite session reset` — сброс статистики сессии.

## Требования

- **Minecraft 26.3** — единственная поддерживаемая версия (Fabric); других линий игры пока нет.
- **Fabric Loader 0.19.5 или новее.**
- **Fabric API** — обязателен; без него мод не загрузится.
- **Java 25 или новее** — лаунчеры обычно ставят её сами для этой версии игры.
- **Только клиент** — мод устанавливается в клиент, на сервере ничего не нужно.

Необязательно: **Mod Menu** — добавляет кнопку SkyLite в список модов (без него всё работает).

## Установка

1. Fabric Loader для 26.3 и **Fabric API** — в папку `mods`.
2. Файл SkyLite — туда же (см. «Сборка» или файлы релиза).
3. Запустить игру. На SkyBlock полоски заменят ванильный HUD; `F6`/`F7` переключают HUD и алерты, `F8` — редактор.

## Сборка

Нужны JDK 25 и Gradle. Пока единственная цель — 26.3:

```bash
bash tools/build_all.sh   # → dist/skylite-0.3.0+26.3.jar
```

`libs/modmenu-21.0.0.jar` нужен только для компиляции (кнопка в Mod Menu) и в готовый JAR не попадает.

## Производительность

- Ноль миксинов — только публичные события Fabric API.
- Полоски и инфо-строки собираются один раз и пересобираются только при реальном изменении значений.
- Сайдбар опрашивается дважды в секунду; пинг-метр живёт в фоновом потоке и полностью останавливается, пока виджет FPS/пинга скрыт.
- Без текстур, моделей, своих шрифтов и звуков — только ванильные ресурсы.

## Раскрытия

**Данные и приватность.** Пока включён виджет FPS/пинга, SkyLite отправляет тому же серверу, к которому ты подключён, крошечный status-запрос серверного списка (примерно раз в 3 секунды), чтобы измерить реальное время отклика. Больше ничего никуда не отправляется; автор не собирает и не хранит данные.

**ИИ-контент.** Проект создан автором совместно с генеративными ИИ-инструментами (ChatGPT и OpenCode). Все решения по продукту, дизайну и тестирование в игре выполнены автором; значительная часть кода написана с помощью ИИ.
