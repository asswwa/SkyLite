# SkyLite

Клиентский Fabric-мод для Minecraft Java: компактный и быстрый HUD для Hypixel SkyBlock. Полоски HP, маны и опыта вместо ванильных элементов, инфо-строки из сайдбара (Defense, область, таймеры Cookie Buff и God Potion, Purse, Bits), плашка скорости, FPS и настоящий пинг в углу, алерты на редкие дропы. Всё рисуется из данных, которые сервер и так присылает клиенту: без миксинов, без текстур, без собственных пакетов.

Поддерживаемая версия игры: **26.3** (Fabric).

## Возможности

- **Полоски HP / маны / опыта вместо ванильного HUD.** Каждая полоска может занять место заменяемого элемента (сердечки, голод, XP-бар): значение внутри полоски (полное / компактное / проценты), символы ❤ ✎, рамка, пульс при низком значении, настраиваемые ширина и толщина.
- **Редактор в игре (F8).** Перетаскивай полоски и плашку скорости куда угодно; колесо — ширина полоски под курсором (Ctrl+колесо — толщина), ПКМ — выбор цвета. Мягкие прилипания к ванильному месту и центру экрана; раскладка переживает смену GUI-масштаба и размера окна.
- **Плашка скорости.** Speed-стат SkyBlock голым процентом — двигается в редакторе, включается/выключается в настройках.
- **Инфо-строки.** Defense, область/остров, таймеры Cookie Buff и God Potion, Purse, Bits — парсятся из сайдбара и action bar, включаются по одной.
- **FPS и настоящий пинг.** В любом углу. Пинг измеряется тем же крошечным status-запросом, что и список серверов, в фоновом потоке — потому что на игровых серверах Hypixel подделывает пинг в табе (там всегда «1»).
- **Алерты (F7).** Звук и вспышка, когда сообщение в чате содержит любое из твоих слов (`RARE DROP!`, …); слова задаются через запятую.
- **Собственный экран настроек.** Только ванильные виджеты — Cloth Config не нужен; Mod Menu необязателен и добавляет лишь кнопку входа.
- **Локализация.** Русский и английский интерфейс.

## Клавиши и команды

| Клавиша | Действие |
| --- | --- |
| `F6` | включить/выключить весь HUD SkyLite |
| `F7` | включить/выключить алерты |
| `F8` | редактор полосок и плашки скорости (переназначается в «Управлении») |

`/skylite` — экран настроек · `/skylite edit` — редактор · `/skylite hud`, `/skylite alerts` — переключатели.

## Установка

1. Fabric Loader для 26.3 и **Fabric API** — в папку `mods`.
2. Файл SkyLite — туда же (см. «Сборка» или файлы релиза).
3. Запустить игру. На SkyBlock полоски заменят ванильный HUD; `F6`/`F7` переключают HUD и алерты, `F8` — редактор.

## Сборка

Нужны JDK 25 и Gradle. Пока единственная цель — 26.3:

```bash
bash tools/build_all.sh   # → dist/skylite-0.1.0+26.3.jar
```

`libs/modmenu-21.0.0.jar` нужен только для компиляции (кнопка в Mod Menu) и в готовый JAR не попадает.

## Производительность

- Ноль миксинов — только публичные события Fabric API.
- Полоски и инфо-строки собираются один раз и пересобираются только при реальном изменении значений.
- Сайдбар опрашивается дважды в секунду; пинг-метр живёт в фоновом потоке и полностью останавливается, пока виджет FPS/пинга скрыт.
- Без текстур, моделей, своих шрифтов и звуков — только ванильные ресурсы.

## Раскрытия

**Данные и приватность.** Пока включён виджет FPS/пинга, SkyLite отправляет тому же серверу, к которому ты подключён, крошечный status-запрос серверного списка (примерно раз в 3 секунды), чтобы измерить реальное время отклика. Больше ничего никуда не отправляется; автор не собирает и не хранит данные.

**ИИ-контент.** Проект создан автором совместно с генеративными ИИ-инструментами (ChatGPT и OpenCode). Все решения по продукту, дизайну и тестирование в игре выполнены автором; значительная часть кода написана с помощью ИИ.
